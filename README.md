“双 ISP”说的是另一回事：这个 IP 同时具备两个 ISP 的属性，在归属判定上更接近真实家庭网络，被识别为代理的概率进一步降低。它和“住宅”是两个维度，理想状态是两条都占。

### 韩国原生 IP 和韩国住宅 IP 是一回事吗

不是。原生 IP 强调的是 IP 归属指向韩国本土运营商，ASN 是韩国的，但它可能是机房段。住宅 IP 进一步要求这段地址属于家庭宽带段。买之前把商品页的措辞看清楚，写“原生”的不等于写“住宅”。

不能保证。IP 只是风控模型里的一个变量，内容质量、账号历史、操作频率都算在内。而且 IP 段会轮换、平台策略会调整，今天能解锁的段下个月未必还行。这也是为什么建议先月付跑一段时间，别一上来就押年付。
